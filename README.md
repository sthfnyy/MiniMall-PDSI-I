# MiniMall - Shopping Local Online

## Sobre o projeto

O MiniMall é uma aplicação web responsiva desenvolvida para facilitar a divulgação e descoberta de produtos comercializados por pequenos e médios lojistas do varejo local.

A plataforma funciona como uma vitrine virtual, permitindo que lojistas divulguem seus estabelecimentos e produtos, enquanto consumidores podem pesquisar, avaliar lojas e entrar em contato diretamente com os comerciantes.

## Objetivo

Fortalecer o comércio local oferecendo uma plataforma organizada para divulgação de produtos e conexão entre consumidores e lojistas.

## Funcionalidades principais

- Cadastro de consumidores e lojistas;
- Gerenciamento de lojas;
- Cadastro e gerenciamento de produtos;
- Busca e filtros de produtos;
- Avaliações de lojas;
- Sistema de pontos e recompensas;
- Favoritos e notificações;
- Administração da plataforma.
